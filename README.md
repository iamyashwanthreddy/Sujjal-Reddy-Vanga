# Sujjal Reddy Vanga — Portfolio

Portfolio site for Sujjal Reddy Vanga, writer, director and editor.

A static site (HTML, CSS, JavaScript) animated with [GSAP](https://gsap.com/) and ScrollTrigger, with [Lenis](https://github.com/darkroomengineering/lenis) smooth scrolling.

## Run locally

Serve the folder with any static server, for example:

```bash
python -m http.server 5173
```

Then open http://localhost:5173.

## Structure

- `index.html` — page markup
- `styles.css` — styles
- `main.js` — animations and interactions
- `assets/` — images and the downloadable resume
